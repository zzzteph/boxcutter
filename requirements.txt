# boxcutter dependencies - one file for every mode.
#
# The lean scanning ENGINE and `boxcutter agent` need only `requests`, PyYAML (workflows) and websocket-client
# (the browser crawler). In the Docker image those come from the base (apk py3-requests / py3-yaml) + a
# websocket-client pip install, so the engine layer never pulls the server deps below. The web SERVER
# (`boxcutter serve`) needs the rest; in the image the whole file installs into a dedicated /opt/srv venv.
